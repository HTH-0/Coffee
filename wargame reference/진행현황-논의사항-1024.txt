[KLOAD 워게임] 진행 현황 및 논의 사항 (10/24)

■ 지금까지 된 것
- 화면 흐름: 메인 → 전투 → (장 클리어) → 다음 장 전투 → 엔딩
- 지도는 전투 화면의 "지도" 버튼을 눌렀을 때만 열림
- 1~4장 몬스터 그림 연결 완료 (정답 맞출 때마다 그림이 다음 단계로 바뀜)
- 2장은 열매 군단 10명이 한 화면에 서 있고, 한 문제마다 한 명씩 쓰러짐
- 문제 40개는 아직 비어 있음 (지금은 테스트 플래그 test로 통과)


■ 논의 사항

1. 전투 화면 배경
- 장마다 배경 그림이 따로 없음
- 지금은 캐릭터 그림을 가운데 카드처럼 띄우고,
  같은 그림을 흐리게 확대해서 뒤에 깔아 둠
- 2장만 메인 화면의 숲 그림을 배경으로 다시 씀
→ 정할 것: 장별 배경(가로 화면 4장)을 따로 그릴지, 지금 방식으로 갈지

2. 몬스터 누끼(배경 지우기)
- 몬스터를 배경과 분리하려고 AI로 배경 지우기를 해 봤는데,
  외곽선과 배경 색이 비슷한 곳은 경계가 깨져서 쓰기 힘든 품질이었음
- 1장: 나뭇잎 머리에 구멍과 덤불 조각이 남음
- 2장: 깔끔해서 지금 군단 화면에 사용 중
- 3장: 어두운 배경과 어두운 몸통이 섞여 외곽선이 무너짐
- 4장: 커피 머신, 컵 같은 소품과 붙어 있어서 분리 포기
→ 정할 것:
  (a) 배경 포함 그대로 쓰기 (지금 상태)
  (b) 그림을 처음부터 단색 배경(흰색/초록)으로 다시 생성 (가장 깔끔함)
  (c) 수작업으로 한 장씩 보정 (작업량 큼)
- 지금까지 작업물은 "wargame reference/누끼 작업중" 폴더에 보관

3. 도트 픽셀 크기
- 캐릭터가 도트 그림인데 화면에 크게 띄우다 보니 도트 한 칸이 약 9px로 크게 보임
- 1장은 원본 해상도가 작아서 오히려 조금 흐릿함
- 2장 군단 화면처럼 작게 띄우면 괜찮음
→ 정할 것: 이대로 갈지 / 화면에 작게 띄울지 / 더 촘촘한 도트로 다시 만들지

4. 4장 기본 상태 그림 부족
- 4장은 기본 그림과 맞았을 때 그림을 비교하면 10칸 중 8칸이 거의 똑같음
- 대부분 이미 아파하는 표정이라, 맞기 전 기본 상태 그림이 사실상 없음
→ 나중에 4장 기본 상태 그림 10장을 추가로 만들어야 함
  (같은 구도, 같은 크기, 맞기 전 평소 표정)

5. 엔딩 / 오프닝
- 엔딩: 지금은 임시 그림. 원래 기획대로 "커피 마시며 쉬는 장면"을 나중에 만들어야 함
- 오프닝: 지금은 없음. 시작하기를 누르면 바로 1장 전투로 들어감
  → 짧은 오프닝 컷(스토리 1~3장)을 넣을지 고민 필요
→ 정할 것: 컷 수, 그림 담당

6. 문제 출제 기준 (가장 먼저 정해야 함)
- 필요한 문제 수: 4장 x 10문제 = 40문제
- 각 문제마다 필요한 것: 제목, 설명, 플래그, (필요하면 문제 페이지 주소)
- 선택지
  (A) PDF 기준: "보스몬스터 워게임 카드 문제 60선"(6분야 x 10문제)에서 40개 고르기
      - 장점: 이미 문제 목록이 있음
      - 단점: PDF의 난이도별 공격력(10/20/30)이 지금 구조(HP 10, 정답마다 -1)와 다름
  (B) 보안 분야 기준: 웹해킹, 리버싱, 포렌식, 암호 같은 큰 분류로 장마다 분야 배정
      - 장점: 장마다 주제가 분명하고, 뒤로 갈수록 어려워지게 맞추기 쉬움
      - 단점: 문제를 새로 정리해야 함
- 참고: 회의에서 "너무 전문적이거나 딥한 내용은 반대, 누구나 공감할 용어"로 의견이 모였음
→ 정할 것: 출제 기준(A/B), 장별 담당자, 플래그 형식
