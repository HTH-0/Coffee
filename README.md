# KLOAD 커피 워게임 (초안 v3)

`index.html`을 브라우저로 열면 바로 실행됩니다. 빌드나 서버는 필요 없습니다.
화면 흐름은 메인 → 전투 → (장 클리어) → 다음 장 전투 → 엔딩입니다.
장 지도(세이브 포인트)는 전투 화면의 "지도" 버튼을 누를 때만 열린다.

## 진행 방식

- 장 4개: 1장 커피나무 → 2장 열매 군단 → 3장 로스팅 → 4장 추출 → 엔딩
- 장마다 몬스터 HP 10. FLAG 를 맞힐 때마다 HP -1, 0 이 되면 다음 장으로 넘어간다.
- 문제 내용은 아직 비어 있다. **테스트 플래그 `test`** 로 모든 문제를 통과할 수 있다.
- 진행 상태는 브라우저 `localStorage` (`kload-coffee-v2`)에 저장된다. 다시 접속해서 이어하기를 누르면 저장된 지점의 전투부터 이어서 진행한다.

## 폴더 구조

```
index.html            메인 / 장 지도 / 전투 / 엔딩 화면
css/style.css         스타일 (기준 해상도 1280x720, 창 크기에 맞춰 확대/축소)
js/data.js            장 정보, 문제 슬롯 (장마다 10개)
js/art.js             장별 몬스터 그림 연결, 지도 장식, 엔딩 그림 (엔딩은 임시 SVG)
js/game.js            진행 로직, 지도, 공격/반격 연출, 장 전환, 저장
assets/               title-bg(메인/지도 배경), ch1~ch4/(장별 단계 그림), 초상화
wargame reference/    기획서, 캐릭터 디자인 원본 시트, 화면 디자인
```

## 문제 서버 (server/)

게임 화면과 장별 문제를 한 서버에서 내보낸다. 문제 페이지는 `/ch2/1/`처럼 장별 주소 아래에 둔다.

```
cd server
npm install
copy flags.example.json flags.json   (실제 플래그로 바꾼다, 저장소에는 올리지 않음)
npm start                            → http://localhost:3000
```

- 검사 봇은 크롬을 쓴다. 경로가 다르면 `CHROME_PATH` 환경 변수로 지정한다.
- 배포할 때는 `ORIGIN`(외부 접속 주소)과 `js/data.js`의 2장 서버 주소를 함께 바꾼다.
- 2장 문제 흐름: 게임 문제보기 창에 문제 페이지가 바로 뜬다 → 알림창이 뜨면 페이지 위쪽에 즉시 표시되고, 페이지가 현재 주소를 서버에 자동으로 보낸다 → 서버 봇이 같은 주소를 직접 열어 확인하면 그 자리에 플래그가 나온다
- 테스트할 때 `http://localhost:3000/?ch=2` 처럼 주소에 장 번호를 붙이면 그 장 1번 문제부터 바로 시작한다

## 문제 채우는 방법

`js/data.js`의 `problems`에서 해당 문제의 `title`, `desc`, `flagHash`, `url`을 채운다.

- `flagHash`가 `null`이면 테스트 플래그 `test`로 통과한다.
- `url`에 `http://` 또는 `https://` 주소를 넣으면 "문제보기" 창 안에 문제 페이지가 열린다. 그 밖의 주소는 무시한다.
- 해시 만들기: `node -e "console.log(require('crypto').createHash('sha256').update('실제플래그').digest('hex'))"`

## 몬스터 그림

`wargame reference/캐릭터 디자인/`의 격자 시트를 칸마다 잘라 배경째로 쓴다. 좌상단 번호와 워터마크는 지웠다.

```
assets/chN/base/f01~f10.webp   기본 모습 (1장 나무몬스터, 2장 커피군단, 3장 생두→원두, 4장 원두→커피)
assets/chN/hit/f01~f10.webp    맞았을 때 모습 (2~4장, 공격 직후 잠깐 보였다가 base 로 돌아감)
```

받은 피해 0~8 → 그림 1~9, 피해 9 → 그림 9, 피해 10(쓰러짐) → 그림 10.
전투 화면은 그림을 가운데 카드로 띄우고, 같은 그림을 흐리게 깔아 배경을 채운다 (`js/art.js`의 `sheet()`).
배경을 지운(누끼) 버전은 외곽선 정리가 더 필요해서 보류했다.

## 참고자료와 아직 반영하지 않은 항목

아래는 결정이 필요해서 반영하지 않았다.

- 난이도 볼(쉬움/보통/어려움)과 난이도별 데미지
- 트레이너(플레이어) 캐릭터와 카드 손패
- 카드 60선, 스킬트리, 계급 시스템 등 다른 기획안의 방식
- 몬스터 그림 누끼(배경 제거) 버전, 지도의 깨끗한 배경 원본
